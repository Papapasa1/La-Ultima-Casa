# La última casa

Juego de terror en primera persona para el navegador, con gráficos sencillos. Es un único archivo `index.html` y no necesita instalar nada.

Juego en desarrollo.

## Cómo jugar

**Controles:** WASD para moverse · ratón o ← → para mirar · Shift para correr · Espacio para saltar · F para la linterna · R para cambiar la pila · E para interactuar · M para el plano · P/Esc para la pausa · B para los trucos
