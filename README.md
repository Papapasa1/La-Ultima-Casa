# La última casa

Juego de terror en primera persona para el navegador, con gráficos sencillos. Es un único archivo `index.html` y no necesita instalar nada.

## Cómo jugar
Abre `index.html` en el navegador, o publícalo con GitHub Pages o Netlify.

**Controles:** WASD para moverse · ratón o ← → para mirar · Shift para correr · Espacio para saltar · F para la linterna · R para cambiar la pila · E para interactuar · M para el plano · P/Esc para la pausa · B para los trucos

## Niveles
1. **La Entrada**: laberinto de pasillos amarillos y una criatura alta que ve en un cono rojo.
2. **El Dormitorio**: pasillo lineal con habitaciones sin puertas, camas para esconderse y una ama de casa gallega que tararea y registra las habitaciones.

## Publicar en GitHub Pages
Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
